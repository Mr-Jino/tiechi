主推版（约 270 字）
────────────────────────

不锈钢装饰这行的报价，是一套设计得挺聪明的模糊。

展开面积不写，只写"按洞口算"；损耗不标，反正都在总价里；焊缝不按米，按"处"；运费一句"看情况"。客户看不懂，就只能点头——点头那一刻，价格就不由他定了。

看不懂不是客户的问题。看不透，才是这门生意的利润来源。

所以我把这套算法开源了。七项成本逐项摆出来，算式直接印在结果里：材料（含算料损耗）、折弯、刨槽、焊接、表面、包装、物流（泡货重货取大）、安装。展开宽度是怎么加出来的、焊缝几米、损耗几个点，一条条能对着看。

不为教谁算账。是为了让"你不懂"这三个字，不能再当报价单用。

算得清的厂，拿它证明自己没坑人；算不清的客户，拿它问三句：展开面积多少、焊缝几米、损耗几个点。这三句问出去，有些报价单会当场改口。

工具不站边，谁都能用。但从今天起，能算的人多了一个。

算得清的厂拿它自证；算不清的客户拿它问三句——展开面积多少、焊缝几米、损耗几个点。

问完，有的报价单会改口。

"加成 30%"的实际利润率是 23.1%。这一条，够不少厂一年白干十几万，账上还一直显示"赚的"。

但更值钱的不是这个：报单价拿"加成 30%"糊自己，拿"按洞口算"糊客户。

算法开源了，两样都能算清。价表自己填。

评论区第一条

仓库：github.com/Mr-Jino/tiechi（复制到浏览器打开）
三句话模板：展开面积多少 ㎡ / 焊缝几米 / 损耗几个点？
对方答不出，或者答"我们都是这么算的"，你就知道这份报价单靠什么在赚钱。
算一单：python -m tiechi.cli quote --w 1000 --h 2100 --d 240
价表 pricebook.json，按自己工厂回填；31 条断言在 Python 3.9/3.11/3.13 上全绿。
