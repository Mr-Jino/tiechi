# 工艺与几何

报价扯皮，八成出在"料怎么算"上。这一节把展开几何的口径写死，省得每次跟客户、跟车间、跟同行各说一套。

## 两种制造工艺

### 拼焊

立边、横边分别下料折弯，到车间拼角焊接。件多、焊缝多，但单件短，不挑板幅。**绝大多数单子走这个。**

### 整包

一块长板连续折弯成"П"形，整圈包住洞口：

```
整包板长 L = 2H + W + 2D + 2×端头余量     （单面包，双包 = 里外各一块）
```

没有拼角焊缝，外观整体感好，但板要够长——1000×2100 的洞口，整包板长 5750mm，标准板最长 3000mm，必然接料。所以整包不是"高端就选它"，要看尺寸。

**整包只支持直边**：弧形要滚弯，整板连续折弯做不了。引擎遇到会自动降级为拼焊并告警，不会硬算出个假数。

## 单包 / 双包

```
单包：只包洞口一面，抱墙折边深度 = min(墙厚, 抱墙上限 40mm)
双包：里外两面都包，每面各抱满墙厚，展开面积翻倍，等于两块板
```

墙厚 240mm 的单包，抱边只有 40mm——现场包不住，师傅会用收边条糊过去。墙厚超过「抱墙上限 + 30」时引擎会提醒改双包，这是质量问题和报价问题的分界。

## 摊平宽度

一条板子摊开后的宽度，是面积计算的根：

```
拼焊：Wd = 套线可见面宽 c + 折边道数 k × 抱墙深度 a + 安装折脚 − k × 0.5 × 板厚
整包：Wd = c + 墙厚 D + 安装折脚 − 2 × 0.5 × 板厚      （按拍板口径，不是 2c+D）
```

其中 `a` 单包取 `min(墙厚, 40)`，双包取墙厚；`k` 是折边道数（1=L 型断面，2=U 型）。

**例**：套线宽 60、单包、墙厚 240、折脚 20、板厚 1.0
→ Wd = 60 + 1×40 + 20 − 0.5 = **119.5mm**

注意这个数比很多人的直觉小：单包抱边封顶 40，不是整个墙厚。

## 焊缝米数

```
拼角焊   ：拼角处数 × Wd + 接料处数 × Wd
满焊无缝 ：全部展开总长（所有拼缝焊满、打磨到看不出）
整包     ：无拼角缝，仅接料缝
装饰线条 ：不对拼整条焊，只算接料缝
```

拼角处数：门套 2 处（上两角），窗套 4 处（四角），整包 0 处。

按米而不是按处计价——套线越宽，同一处拼角的焊缝越长。

## 折弯米数与道数

```
拼焊件   ：每条料 长度 × 折边道数
整包板   ：2 道纵向通长折 × 板长 + 2 个端头转角折 × 摊平宽度
```

折弯道数（按道计价时用）：拼焊件 = 条数 × 折边道数；整包板 = 2 道通长 + 2 道端头。

滚弯单独计米，不并入折弯——弧形板走的是滚弯机，工时和单价都不同。

## 弧形：上圆角 / 半圆拱

**上圆角**（半径 R 用户填）：

```
立边长   = H + c + 端头余量 − R      （圆角吃掉立边顶上的一段直线）
顶横边长 = W + 横边加长 − 2R + 端头余量
圆角弧长 = π/2 × R
```

**半圆拱**（半径由洞口宽推）：

```
R       = (W + 横边加长) / 2
立边长  = H − R + 端头余量
拱顶弧长 = π × R
```

弧件的外形都不开槽、只滚弯，不计折弯道数。

**开裂下限**：冷弯半径低于 `20 × 板厚` 会开裂（1.0mm 板 → 20mm）。引擎在半径不够时直接报"会开裂"，这个不是建议，是物理限制。

## 板幅与拼板/接料

标准板：宽 1220 / 1500，长 2440 / 3000。

```
摊平宽度 > 最大板宽 → 每超出一次算一处拼板
单件长度 > 最大板长 → 每件算一处接料
```

拼板和接料都是双份成本：料钱 + 焊工。所以窄套线用大板幅反而更省——引擎会同时给出板材张数和利用率，低于 55% 会提示套裁。

## 窗台板

窗套可选带窗台板，一件拆成两条：

```
窗台板  ：长 = W + 2×耳朵 30mm，摊平宽 = 墙厚 + 前出檐 25mm
窗台前沿：长 = W + 2×30mm，摊平宽 = 挡水沿 20mm
```

耳朵是两侧各伸出 30mm 盖住墙洞，前出檐 25mm 是台面挑出，挡水沿 20mm 是前面那道立边。

## 装饰线条

不按套算，按米卖：

```
展开面积 = 摊平宽 × 每条长 × 条数
延米数   = 条数 × 每条长        ← 报价页"延米价"模式直接按这个收钱
折弯     = 每条 2 道边
接料     = 每条长超板长时，每条各算一处接料
```

这是"延米价"定价模式最典型的场景：老板微信里只报"60 米线条"，价格随口就是"45 一米"。

## 一个完整的例子

洞口 1000×2100，墙厚 240，304 / 1.0mm，拉丝，双包，拼焊，套线 60：

| 件名 | 条数 | 单条长 | 摊平宽 | 展开面积 |
|---|---|---|---|---|
| 立边 | 4 | 2175.0mm | 319.5mm | 2.780㎡ |
| 顶横边 | 2 | 1075.0mm | 319.5mm | 0.687㎡ |
| | | | **合计** | **3.467㎡** |

- 含损耗（直边 8%）：3.744㎡ × 172.5 元/㎡ = **￥645.82**
- 折弯 10.85m × 14 = **￥151.90**；焊缝 0.639m × 50 = **￥31.95**
- 表面 3.467㎡ × 28 = **￥97.06**；包装 60 + 3.467×18 = **￥122.40**
- 物流 max(0.659m³×180, 32.7kg×1, 45) = **￥118.70**；安装 **￥150**（同城）
- 总成本 **￥1,317.84** → 加成 30% → 取整 → **报价 ￥1,714**，实际利润率 23.1%

同一单改成整包：总成本 ￥1,545.50，报价 ￥2,010——多花 293 元买"没有拼角焊缝"，值不值由客户决定，但价格得报得出来。
