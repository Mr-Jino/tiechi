# 成本模型

一份报价的可信度，取决于每一分钱能不能指着算式说清楚。这里是七项成本的口径，以及三个最常见的报亏原因。

## 总公式

```
总成本   = 材料费 + 折弯费 + 刨槽费 + 焊接费 + 表面处理费
           + 包装费 + 物流费 + 安装费

建议报价 = 总成本 × (1 + 成本加成率)        ← 默认口径
        或 总成本 ÷ (1 − 销售利润率)        ← 价表里填了销售利润率时
```

## 1. 材料费

```
净展开面积 = Σ(每条料：条数 × 长度 × 摊平宽度) ÷ 10⁶     单位 ㎡
损耗率     = 按造型取（直边 8% / 上圆角 12% / 半圆拱 15% / 异形 15%）
             + 需拼板时再加 3%
材料费     = 净面积 × (1 + 损耗率) × 板材单价[材质][板厚]
```

**为什么用"材质 × 板厚"实价表，而不是"基准价 × 材质系数"**：系数会漂移。201 涨 5% 和 304 涨 5% 不是同一个绝对值，乘一个固定系数，两个月后全错。实价表丑，但改价的时候只需要改那个格子。

## 2. 折弯费

两种计价方式，价表里 `折弯.计价方式` 切换：

```
按米：折弯费 = 直边折弯米数 × 直边折边元每米 + 滚弯米数 × 滚弯元每米
按道：折弯费 = 折弯总道数 × 直边折弯元每道 + 滚弯米数 × 滚弯元每米
```

滚弯永远按米——弧形板上机器走的是弧长，不是"道"。

**折弯扣减**：每道折弯会让展开长度少半个板厚（板料中性轴），所以摊平宽度里要扣 `道数 × 0.5 × 板厚`。价表支持按板厚单独指定扣减（`折弯扣减mm按板厚`），没配就走老口径。这个修正对薄板无所谓，对 1.5mm 以上的厚板是实打实的料钱。

## 3. 刨槽费

```
刨槽费 = 折弯米数 × 刨槽元每米
```

刨槽是在折弯线开一道 V 槽，折完内角接近直角（R≈0），拼角外观更挺直，电梯门套和精装单常用。槽长约等于折弯米数，所以直接乘。注意：刨槽后摊平宽度的扣减按 0 算（几乎不占料），且只对直边折弯有效——弧形件开不了槽，引擎会自动忽略并告警。

## 4. 焊接费

```
拼角焊：焊缝米数 = 拼角处数 × 摊平宽度 + 接料处数 × 摊平宽度
满焊无缝：焊缝米数 = 全部展开总长（所有拼缝焊满后打磨到看不出）
整包：拼角处数为 0，只有接料缝

焊接费 = 焊缝米数 × 焊缝元每米 + 接料处数 × 拼板接料元每处
```

焊缝按米计价，不按处——同样一处拼角，套线宽 60mm 和 260mm 的焊缝长度差四倍，按处报价是把钱送给客户。

## 5. 表面处理费

```
表面处理费 = 净展开面积 × 工艺单价 × 计价面数 × 弧形难度系数
```

- 计价面数：只做外露面填 1，里外都做填 2；
- 弧形难度系数（默认 1.15）：滚弯后表面要重新抛光/返工，弧形件按上浮计。

**注意台阶效应**：镀钛 118 元/㎡ 对比拉丝 28 元/㎡，同样一件活表面费差四倍。给客户改色之前先算一遍，别口头答应"改成黑钛差不多钱"。

## 6. 包装费

```
包装费 = (单套基础费 + 单套净面积 × 每平米护边费) × 套数
```

木架/纸箱是固定成本，护边按面积走。批量越大，基础费摊得越薄。

## 7. 物流费

```
模板估算：max(打包体积 × 元/m³, 重量 × 元/kg, 最低一票)
手动填写：直接用填的整单运费
```

**泡货与重货取大**是这条公式的全部意义。不锈钢看起来重，但门套是大面积薄板，打包后往往按体积计费更贵——按重量算会系统性低估运费。

- 重量 = 含损耗面积 × 7.93kg/(㎡·mm) × 板厚 × 1.10（+10% 辅料焊材）；
- 打包体积 = 捆数 × 捆宽 × 捆高 × 最长件 + 0.02（打底）。

## 8. 安装费

```
安装费 = 品类单价 × 套数 + (非同城 ? 异地差旅 × 套数 : 0)
```

装饰线条这类没有安装单价的品类自动为 0。

## 定价：加成率不是利润率

这是行业里最常见的报亏原因，值得单独说：

```
加成 30%：报价 = 成本 × 1.30   →  实际利润率 = 0.30 / 1.30 = 23.1%
利润 30%：报价 = 成本 ÷ 0.70   →  实际利润率 = 30%
```

差 7 个百分点。一年做 300 万的活，这个口径差出去二十多万毛利，而且没人会发现——因为每个月账上都是"赚的"。

价表里两个字段二选一：`成本加成率` 填 0.30（默认），或者把 `销售利润率` 填 0.30（此时加成率失效）。引擎会按填的口径算，并把实际利润率印在结果里。

**取整**：`取整元` 默认 1，改成 5 或 10 就是报价取整到 5/10 元。行业习惯向上取整，别让客户看见 ¥1,713.62 这种数字。

**延米价模式**：老板脑子里通常有一个市场锚（"304 拉丝门套 420 一米"）。填 `pricing_mode=延米价` + `target_linear_price=420`，引擎按延米数出总价，并用成本反推毛利；低于成本时直接告警"亏本单"。

## 置信度三档

```
低 = 用的还是出厂示例价表 → 只能看个大概
中 = 你改过价表（贴近自己工厂的实际成本）
高 = 用实单回填校准过（meta.calibrated = true）
```

校准方法：拿历史 5~10 单，用引擎复算，跟实际结算价对比。偏差都在 5% 以内就标"已校准"；某一项系统性偏移，就回去改那一项的参数——八成是物流或损耗。
