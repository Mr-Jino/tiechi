## 单独跑一单

```bash
tiechi quote --w 1000 --h 2100 --d 240 --surface 拉丝 --detail
tiechi quote --preset 电梯门套
tiechi quote --material 201 --thickness 0.6 --surface 镀钛 --shape 半圆拱 \
             --w 2600 --h 2800 --d 500 --face 260 --wrap 单包
```

## 触发告警的最短路径

```bash
# 201 镀钛 → 建议改 304；0.6mm 宽套线 → 波浪纹；单包大墙厚 → 建议双包
tiechi quote --material 201 --thickness 0.6 --surface 镀钛 \
             --face 200 --wrap 单包 --d 500

# 圆角半径 10mm < 20×板厚 → 会开裂
tiechi quote --shape 上圆角 --arc 10 --thickness 1.0

# 延米价低于成本 → 亏本单
tiechi quote --set pricing_mode=延米价 --set target_linear_price=100
```
